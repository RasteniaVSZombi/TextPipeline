# TextPipeline

## Описание

**TextPipeline** — настольное WPF-приложение для обработки текстовых данных с использованием контрактов операций.

Проект разработан в рамках лабораторной работы «Контракты в интерфейсе». Основная идея приложения заключается в том, чтобы для каждой операции явно задавать предусловия (**Pre**) и постусловия (**Post**) и отображать их состояние непосредственно в пользовательском интерфейсе.

## Технологии

* C#
* .NET 8
* WPF
* MVVM
* xUnit
* `Debug.Assert`
* `Guard` для проверки предусловий

## Реализованные операции

### 1. Нормализация текста

Операция приводит текст к единому виду:

* удаляет пробелы в начале и конце строки;
* заменяет последовательности пробельных символов одним пробелом;
* переводит текст в нижний регистр.

Пример:

```text
Вход:
  Hello    WORLD   Test

Результат:
hello world test
```

**Pre:** входная строка не должна быть `null`.

**Post:** результат не содержит лишних пробелов и приведён к нижнему регистру.

---

### 2. Фильтрация текста

Операция позволяет оставить в строке только выбранные категории символов:

* буквы;
* цифры;
* прочие символы.

Пример:

```text
Вход:
Hello123!@

Выбрано:
Цифры

Результат:
123
```

**Pre:**

* входная строка не должна быть `null`;
* должен быть выбран хотя бы один тип символов.

**Post:** все символы результата соответствуют выбранным типам.

---

### 3. Применение маски

Операция формирует строку в соответствии с заданной маской. Символ `#` используется как позиция для подстановки символов входной строки.

Пример:

```text
Вход:
1234567890

Маска:
+7 (###) ###-##-##

Результат:
+7 (123) 456-78-90
```

**Pre:**

* входная строка не должна быть `null`;
* маска не должна быть `null`;
* маска должна содержать `#`;
* во входной строке должно быть достаточно символов для заполнения маски.

**Post:**

* все позиции `#` заполнены;
* остальные символы маски сохранены;
* результат соответствует заданному формату.

## Контракты операций

Для каждой операции в приложении предусмотрен отдельный контракт, содержащий:

* название операции;
* предусловие (**Pre**);
* постусловие (**Post**);
* эффекты и исключения;
* валидный пример;
* невалидный пример.

Состояние предусловия и постусловия отображается в главном окне приложения с помощью соответствующих индикаторов.

## Запуск проекта

Для запуска проекта требуется:

* Windows;
* .NET 8 SDK;
* Visual Studio с поддержкой разработки приложений .NET Desktop.

Порядок запуска:

1. Открыть файл решения проекта в Visual Studio.
2. Убедиться, что в качестве запускаемого проекта выбрано WPF-приложение `TextPipeline`.
3. Выполнить сборку решения.
4. Запустить приложение.

## Тестирование

Для проверки операций предусмотрен отдельный проект с тестами.

Тесты проверяют как корректные сценарии, так и граничные случаи:

* обработку `null`;
* пустые входные данные;
* отсутствие выбранных параметров;
* недостаточное количество символов для маски;
* корректность получаемого результата.

Запуск тестов осуществляется средствами **Test Explorer** в Visual Studio.

## Архитектура

Приложение построено по архитектурному шаблону **MVVM**.

Основные компоненты:

* **View** — XAML-интерфейс приложения;
* **ViewModel** — управление состоянием интерфейса и взаимодействием с пользователем;
* **Domain** — операции обработки текста и контракты.

Для каждой операции предусмотрена отдельная ViewModel:

* `NormalizeViewModel`;
* `FilterViewModel`;
* `MaskViewModel`.

Общая функциональность вынесена в `OperationViewModelBase`.

## Цель проекта

Основная цель проекта — продемонстрировать применение контрактного подхода при разработке программного обеспечения: формулирование предусловий и постусловий, их проверку во время выполнения и отображение состояния контрактов непосредственно в пользовательском интерфейсе.
